 # 📚 Library Management System

A modern, full-stack Library Management System built for B.Tech CSE | DBMS Project | Brainware University.

## 🎯 Features

- ✅ Role-based access control (Admin, Librarian, Assistant)
- ✅ Book management (Add, Edit, Delete, Search)
- ✅ Member management
- ✅ Loan tracking (Issue/Return books)
- ✅ Fine calculation and management
- ✅ Analytics & Reports
- ✅ Responsive design (Mobile-friendly)
- ✅ Real-time search & filtering

## 🛠️ Tech Stack

**Frontend:**
- HTML5, CSS3, Vanilla JavaScript
- Hosted on GitHub Pages

**Backend:**
- Python Flask
- Hosted on Render.com

**Database:**
- MySQL
- Hosted on Clever Cloud
